# portfolio

Personal website of Nadeem Nazer: https://nadeemn.github.io/portfolio/

Plain HTML/CSS/JS with no build step, served by GitHub Pages from `main`.

```
index.html            all page content (news, publications, experience, projects, …)
assets/css/style.css  styles; colour tokens for light/dark mode at the top
assets/js/main.js     theme toggle, mobile menu, active nav link
assets/img/           profile photo, company logos, paper teaser figures
```
